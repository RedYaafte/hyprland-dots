# Black Ember

The default watercolor wallpapers are bundled in
`assets/wallpapers/black-ember/` and are installed to
`~/Wallpapers/black_ember/` when absent.

Tema personal de forja nocturna: carbón, acero quemado, bronce envejecido y
una brasa ámbar contenida. Es una identidad visual original del setup; no
depende de Omarchy ni de Mechanoonna.
